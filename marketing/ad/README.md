# Nudge — launch ad

> This folder is part of Nudge's brand assets and is covered by the [Nudge Brand License](../../LICENSE-BRAND.md), not the Apache License. The rendered `Nudge-Ad-1440.mp4` and `soundtrack.wav` aren't committed; rebuild them with the commands below.

A 19-second, 1440×1440, 60 fps ad for Nudge, built entirely in code. The picture and the sound share one cue sheet, so every beat lands.

| File | What it is |
|---|---|
| `Nudge-Ad-1440.mp4` | The rendered ad, H.264 with AAC audio |
| `index.html` | The ad. Driven only by `seek(t)`, with no CSS transitions or timers. Open it in a browser to preview with sound (Space plays and pauses). |
| `cues.js` | The shared timeline, at 120 BPM in 4/4 |
| `soundtrack.mjs` | The original score and sound design, synthesized into `soundtrack.wav` |
| `render.mjs` | Renders frames in headless Chromium and encodes the MP4 with ffmpeg |

## Rebuild

```sh
node soundtrack.mjs      # writes soundtrack.wav
node render.mjs          # writes Nudge-Ad-1440.mp4
node render.mjs --stills 4.9,8.3   # PNG stills for checking a moment
```

Requires Node 22+, ffmpeg, and a Chromium or `chrome-headless-shell` binary (found in the Playwright cache, or set `CHROME`).

## Adapting to other shapes

The key action in each shot sits near the center of the square, so 9:16 and 16:9 versions can be cut from this composition. To change the frame, adjust the stage size in `index.html`, the viewport in `render.mjs`, and the camera zooms in `buildTimeline()`.
